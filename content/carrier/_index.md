## Aether's Hope - G0N-GKG

The fleet carrier serving as mobile base of operations: refuel, rearm, and a
jump range that beats any ship in the fleet over long hauls.

| | |
|---|---|
| Name | Aether's Hope |
| Callsign | G0N-GKG |
| Jump range | ~500 ly per hop |
| Jump cycle | ~15-16 min countdown + ~5 min cooldown |

Carrier hops cover roughly 490 ly per cycle - which works out to about
1,400 ly/hr, comfortably faster than flying it in most ships.
